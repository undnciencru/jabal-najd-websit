# موقع شركة جبل نجد القابضة — نسخة قابلة للتعديل

تحتوي هذه النسخة على الصفحة الرئيسية وصفحة «من نحن» المستقلة وجميع الصور والخطوط وبروفايل الشركة.
الموقع مكتوب بلغة HTML وCSS وJavaScript. لا توجد خطوة بناء أو مكتبات مطلوب تنزيلها.

## الفتح في Visual Studio Code

1. فك ضغط الملف ZIP.
2. افتح برنامج Visual Studio Code.
3. اختر **File → Open Folder** ثم اختر مجلد **Jabal_Najd_Website** الذي يحتوي على `index.html`.
4. افتح الملف المطلوب وعدّل النصوص أو الألوان، ثم احفظ التعديل.

## معاينة الموقع أثناء التعديل

إذا كنت تستخدم إضافة Live Server، اضغط بالزر الأيمن على `index.html` واختر **Open with Live Server**.

ويمكنك استخدام أداة المعاينة المرفقة إذا كان Node.js مثبتًا على جهازك:

1. افتح **Terminal → New Terminal** داخل مجلد المشروع.
2. شغّل الأمر:

```sh
npm start
```

3. افتح `http://localhost:5500/` في المتصفح. لا تحتاج إلى `npm install`.
4. بعد حفظ التعديلات، حدّث صفحة المتصفح. لإيقاف المعاينة اضغط `Ctrl+C` في الطرفية.

يمكن أيضًا فتح `index.html` مباشرة في المتصفح؛ جميع مسارات الصفحات والصور أصبحت نسبية. استخدم المعاينة المحلية لعرض الخطوط بأفضل توافق مع المتصفح.

## أهم الملفات

| الملف | الاستخدام |
| --- | --- |
| `index.html` | نصوص وتوزيع الصفحة الرئيسية |
| `about/index.html` | محتوى صفحة «من نحن»، والرؤية والرسالة والأهداف والقيم |
| `styles.css` | الألوان والخطوط والمسافات وتنسيق الجوال |
| `site.js` | قائمة الجوال وتحديد القسم الحالي أثناء التمرير |
| `assets/` | صور الموقع والشعار وبروفايل الشركة |
| `assets/fonts/` | الخطوط المحلية |
| `preview.cjs` | أداة المعاينة المحلية |

لتغيير الألوان الرئيسية ابحث عن `:root` في بداية `styles.css`؛ يحتوي هذا الجزء على متغيرات الألوان مثل `--navy` و`--gold`.

النسخة المحلية مستقلة. حفظ التعديلات فيها لا يحدّث الموقع المنشور تلقائيًا؛ يلزم نشر الملفات بعد التعديل لتحديث الموقع.
